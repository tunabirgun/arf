The quiet machine

The on-device machine

Small, open, optional, and your notes never leave the device.

The reason note collections fail is rarely that capture was too hard. It is that notes pile up faster than anyone connects them, and the insight that was supposed to emerge stays buried in a heap. Arf's suggestions are meant to help with that: not to write for you, but to point out when two of your own notes belong together.

How it works, briefly

A sentence-embedding model reads a note and produces a list of 384 numbers that stands for what the note is about. Notes about the same idea end up with similar lists even when they share few words, which is how Arf can notice a connection you never spelled out. The closeness of two notes is the cosine of the angle between their lists: values near 1 mean the notes are about the same thing, values near 0 that they are unrelated.

The model runs in the background on your own hardware. Each note's numbers are cached on your device, so nothing is recomputed until you change the text.

The model is optional. With connection suggestions off, which is how Arf starts, Resonance and Synthesis compare notes by the distinctive words they share. That is instant and needs no download, but it only sees words, not meaning.

Choosing a model

No model ships inside the installer. Open Settings → Connection suggestions, turn suggestions on, and pick a model from the list; Arf downloads it once and keeps it. Each row shows the model's languages, download size and licence, with buttons to download it without switching to it, to use it, and to remove its files again.

The model runs on the computer's processor (WebAssembly), so no graphics card is needed. The first time a model is used, Arf embeds every note once and shows Indexing n / N in the side panel; in the desktop app with a 304-note test vault this took about 0.3 s per note with ArfLLM and 0.5 s with ArfLLM_Multi. After that, only notes you change are embedded again.

The two Arf models are described in full on their model cards, including training data, evaluation, and limitations. In short: fine-tuned English candidates did not pass the acceptance rule fixed before training, so ArfLLM is published as an export of the base model and makes no quality claim. ArfLLM_Multi was trained on English arXiv titles and abstracts and on short sentence pairs in 12 languages; no improvement is claimed for non-English scientific text, and only the first 256 tokens of a long note are read.

When a suggestion appears

Each model places notes on its own scale of similarity, so a cut-off that suits one model is too strict or too loose for another. Arf therefore gives every listed model its own two thresholds: a lower one for Resonance and a higher, stricter one for Synthesis. They were set on a collection of English arXiv notes so that the share of unrelated note pairs clearing each threshold is the same for every model. Switching models changes which notes look related, but not how often unrelated pairs slip through.

A model you add yourself has no such calibration. For it, Arf looks at your own vault: it compares random pairs of your notes, which are mostly unrelated to each other, and places the Resonance threshold above 90 % of those similarities and the Synthesis threshold above 99 %. This needs at least 29 notes with some text in them; with fewer, Arf keeps using word overlap.

Private by construction

The model runs on your device, and note text never leaves it. Turning suggestions on contacts huggingface.co and its file CDN for the model files, and cdn.jsdelivr.net for the onnxruntime-web runtime that executes the model (up to about 27 MB, once). Arf checks every runtime file against a SHA-384 hash recorded when the app was built and refuses any file that differs, and model files are pinned to the repository version current at download. These are plain file downloads; nothing about your notes is sent.

Where it shows up

The suggestions are deliberately quiet. They never interrupt, and they appear in four places:

While writing

A faint mark

When the paragraph you are writing shares distinctive words with a note it does not link to, a small mark appears in the margin; click it to insert the link. Keep typing and it fades. This mark always uses word overlap.

On the page

Resonance

Up to five notes most similar to the one you are reading that you have not linked yet, each with a + link button. They also appear in the graph as dashed edges.

Across the vault

Synthesis

Opened from the top bar: a handful of note pairs that are alike but were never connected, with the words they share and a button to link them.

Left alone

Orphan mark

A note with no links carries a hollow mark, so you can see what has not yet been placed.

Reading the scores

With a model in use, Resonance shows each note's similarity score, the cosine described above, rounded to two decimals, and the panel heading names the model. Without a model the scores measure word overlap on a different scale, so they are kept out of sight and shown only when you point at a row.

Honest about its limits

General text models read source code poorly, so fenced code blocks are set aside rather than allowed to blur a note's meaning. The thresholds were calibrated on English research notes, not on your notes or on other languages. And a suggestion is only an invitation to look, never a claim that two notes must be joined.
